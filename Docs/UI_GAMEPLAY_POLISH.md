# REAL CRICKET 3D — UI and match-flow polish

This branch makes a first integration pass on the existing Unity prototype. It keeps the current batting, bowling, running, scoring, fielding, career-save and tournament systems in place.

## Changes

- Reworks the generated match setup into a full-screen modal with a centered dark setup card and gold accent.
- Places gameplay controls and the scoreboard in a separate gameplay HUD root. The root stays hidden while match setup is open, so the old batting/bowling buttons no longer show through the setup screen.
- Uses a scale-with-screen-size Canvas Scaler with a 1920×1080 reference resolution and a balanced width/height match setting.
- Adds larger, explicitly sized match setup buttons and best-fit labels.
- Enables BAT/BOWL toss decisions only after a valid toss; changing either team or the match format clears the previous toss.
- Displays the selected match format alongside the selected teams.
- Applies the independent REAL CRICKET 3D / REAL CRICKET STUDIOS identity and a black-and-gold dashboard palette.
- Routes Quick Match, Tournament and Test Match to their matching existing flows. Modes without an implemented flow are disabled and labelled Coming soon.

## Regenerate the prototype scene

The UI is generated by the Editor scene builder. After pulling this branch:

1. Open the project with Unity **6000.6.4f1**.
2. Wait for scripts to compile and check the Console for errors.
3. Use **RealCricket3D → Build Prototype Scene**.
4. Open `Assets/Scenes/CricketPrototype.unity` and press Play.

The builder regenerates the greybox scene. Back up any manual scene edits before running it.

## Required validation

This source update has not been compiled or play-tested in the Unity Editor in this environment. Before treating it as verified, test:

- T20, ODI and Test setup; team switching; toss; BAT/BOWL selection.
- Four-team cup launch and next-fixture progression.
- Batting swipe, shot buttons, running, bowling variations, pause/resume and score updates.
- Match completion, result panel and career/tournament progression.
- Landscape Android layouts at narrow and wide aspect ratios, including safe-area cut-outs.

This is a UI and match-flow polish pass on a prototype, not a claim that production-quality player/stadium assets, complete cricket rules, online multiplayer or a release-ready Android build are finished.
